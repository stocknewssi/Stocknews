# StockNewsWala Android App

This is a separate Android Studio project for the StockNewsWala website.

## App behavior
- Opens the official StockNewsWala website: https://stocknewswala.stocknews1822.workers.dev/
- Includes a loading indicator and Android back-button navigation.
- Uses the existing website/backend, so it does not pretend to supply separate market data.
- Internet permission is required.

## Build an APK
1. Install Android Studio on a computer.
2. In Android Studio, choose **Open** and select this repository's `android-app` folder.
3. Allow Gradle sync to finish.
4. Select **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
5. Android Studio will show the generated APK location.

This repository change is a starter project, not a built or tested APK. Build and test it on an Android device before publishing.
